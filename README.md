📖 About
BookShelf is a Single Page Application (SPA) built with React and Firebase Firestore.
It allows users to add, view, edit, and delete books from a personal library.

🚀 How to Run Locally

Clone the repository

git clone https://github.com/YOUR_USERNAME/book-library.git

Install dependencies

npm install

Add your Firebase config in src/firebase/config.js
Start the app

npm run dev

Open in browser

http://localhost:5173

✅ Features

SPA routing with React Router DOM
Create a book (form with validation)
Read all books (card grid layout)
Read single book (dynamic route /books/:id)
Update a book (pre-filled edit form)
Delete a book (confirmation modal)
Search/filter books
Fully deployed on Vercel / Firebase Hosting
